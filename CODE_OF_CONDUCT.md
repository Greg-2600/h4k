# Contributor Covenant Code of Conduct (short form)

h4k is a lab tool for authorized testing. Participation — issues, PRs,
discussions — is open to everyone acting in good faith.

## Expected

- Use h4k only against systems you own or have written permission to test.
- Never post real credentials, live target IPs, or customer data in issues/PRs.
- Be specific and kind in review; assume the reporter is testing their own lab.

## Unacceptable

- Using issues/PRs to request or share attacks against third parties.
- Posting leaked data, creds, or PII.
- Harassment, hate speech, or sexualized content.

## Enforcement

Violations may be removed and accounts blocked at maintainer discretion.
Report conduct issues privately via the profile email on the repo owner page,
or via [private vulnerability reporting](../../security/advisories/new) for
security-sensitive matters.
